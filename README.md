# Working Dashboard

A very small static dashboard for Jackie Gao.

## Open locally

Open `index.html` directly in your browser, or serve the folder with a local web server.

## Run a local server

From this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Where to put the real resume

Put your real resume page and related assets in:

`projects/resume/`

The current entry point is:

`projects/resume/index.html`

You can replace that placeholder page with your finished resume HTML whenever you are ready.

## Git basics

To commit changes:

```bash
git status
git add index.html styles.css README.md projects/resume/index.html
git commit -m "Create working dashboard"
```
